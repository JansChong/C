问题1： 
    取地址操作时
    &p  
    *p
    p
    的区别;
    ===================
    输出和赋值时
    &p  
    *p
    p
    的区别; 

    （已解决： 假设p是一个指针变量， 那么p就指向一个地址， *p等于指向的地址的值（解引用）， &p则是p这个指针变量自身在内存中的地址）


问题2： 
    数组只能存储单一的数据类型？？ 
    (已解决： ‌是的，在 C 语言中，数组只能存储单一的数据类型)


问题3： 对整个数组的地址赋值？
    （已解决：
    在c中，数组的地址 等于数组名， 数组名等于数组首个元素的地址， 所以数组的地址等于数组首个元素的地址， 注意：偏移不是 
    <偏移数组的地址会移到其他地方，偏移数组首个元素的地址则会访问数组的下一个元素>
    所以对数组的地址赋值是不可行的， 数组名也是一个 "常量指针" ）


问题4： 指针变量 不能 用scanf 的 &p 赋值？
    (已解决：如下)

    int a = 10;
    int *P = &a;  // 把a的地址存给指针变量 p

    scanf("%d", p); // 输入的值赋给p,  即修改a的地址中的值 
    scanf("%d", &p); // &p是指针变量p 自身在内存中的地址，输入的值会强行变成指针变量P的地址=> 逻辑错误
    scanf("%d", *p); // *p是解引用，表示p指向的地址(a的地址)的值 10,  只读区 不可写入

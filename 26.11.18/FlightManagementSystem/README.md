# Airline_Administrator

### 航司管理员功能 （管理员限制20位，用顺序表存储结构体）
1. 管理员注册登录
    1. 注册： 名称、密码、工号(自分配，用数组最后一个元素)、所属航司、
    2. 登录成功 可以管理 其航司名下航班 + 其航司参与的联合航班，包括：
2. 航班信息录入： 允许管理员输入新航班的详细信息，包括航班号、目的地、出发地、出发时间和可用座位数，并将该航班信息存储到系统中。
3. 航班行程取消
4. 航班信息更新
5. 航班信息显示
6. 允许管理用户信息，包括添加新用户、删除用户、更新用户信息和查看用户列表。
    + 这里只能管理当前航司的用户，
    + 如果用户坐了本航司的航班，就将该用户加入 航司客户表中 
    + （并给该用户设置：姓名、飞行次数、 用户状态：0拉黑、 1正常、 是否会员：0否、1是）
7. 航司信息中要存储： 
    + 航司名称
    + 航司员工, 
    + 航司客户表，
    + 旗下航班（遍历航班信息数据链表）
    + 合作航班（遍历合作航班数据链表）
    + TODO..航班状态[可预定、可购买、可值机、候机、航班起飞、航班到达]，
8. 系统退出

## 用户
1. 注册用户
2. 用户登陆
3. 查看全部航班
4. 选择一个航班 (输入数字-1即为航班下标) 
    + 用该航班的航班号执行 步骤5
5. 输入航班号查询某个航班
    + 该航班不存在
    + 该航班存在, 判断是否为联合航班
        + 否 - 直接读取航班信息的 
            + 该航班存在但无座位
            + 该航班存在且有座位
                - 航棒号 出发/到达  席位  数量  价格 
        + 是 
            - 在联合航班中查找当前航班 
            - 输出各个合作航司信息(含承载航司) + 分配各仓位的座位数 + 分配各仓位的价格
                - 显示  席位 数量 价格 (这里应该加一个属性, 自动计算所有舱位数量之和)
    + 如存在, 输入席位 (席位-1即为下标)
        - 目标航班信息, 目标席位-1
        - 添加行程到该用户 (该用户添加到 航司链表 - 客户链表中 )

## 航班管理系统

1. 航班信息（flight_info） - 航班链表
    头文件 
    结构体定义： 
        | 航班号
        | 承载航司 |
        | 是否为联合航班
             | 如是： （跳转到联合航班信息录入） 
             | 如不是： 分配各仓位的座位数 | 分配各仓位的价格 | 输入燃油基建费 
         出发地 | 目的地 | 出发时间 | 到达时间 | 
    初始化 和 函数定义

2. 用户信息（user_info） - 用户链表
    头文件
    初始化 和 函数定义

3. 超级管理员(super_manager) - 超级管理员用户链表
    头文件
    初始化 和 函数定义

4. 航司管理员(flight_manager) - 航司管理员用户链表
    头文件
    初始化 和 函数定义

5. 联合航班信息(joint_flights) - 联合航班链表
    头文件
    结构体定义： 
        | 航班号（传参存储） |  输入各个 合作航司信息(含承载航司) + 分配各仓位的座位数 + 分配各仓位的价格 | 输入燃油基建费 
    初始化 和 函数定义
